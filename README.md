# Cougar-Nation
It's like the backrooms but with APs

## Crafting
- Crafting grid is **3x3**.
- 1 stool -> 2 wooden planks.
- 9 screws -> 1 iron ingot.
- 3 iron ingots + 2 wooden planks -> 1 axe.
- 1 rubber duck, trash bin, or water bottle -> 1 plastic.
- 1 backpack, pair of shoes, or red ribbon -> 1 fabric.
- 1 fabric + 1 screw + 7 plastic -> 1 hall pass.
